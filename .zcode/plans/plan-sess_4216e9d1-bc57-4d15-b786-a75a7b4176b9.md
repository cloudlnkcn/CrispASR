## 目标

在 `.github/workflows/release.yml` 中新增一个 Intel SYCL 发布构建任务，产出 `crispasr-linux-x86_64-sycl.tar.gz`，为 Intel GPU（Arc / Data Center Max / Flex / iGPU）用户提供独立二进制。沿用现有 Vulkan/CUDA/HIP job 的「apt 在线安装 + 运行时库打包 + RPATH」模式，保持完全自包含。

## 改动文件

仅一处：`.github/workflows/release.yml`

## 具体改动

### 1. 新增 job `build-linux-x86_64-sycl`

插入位置：`build-linux-x86_64-vulkan` job 结束后（约 line 593）、`build-linux-arm64` 之前，与其它 Linux GPU 变体归在一组。

job 结构（仿 `build-linux-x86_64-hip` + `build-linux-x86_64-vulkan`）：

```yaml
  # ── Linux x86_64 CLI — Intel SYCL variant ───────────────────────────────────
  # Intel GPU 专用路径（Arc / Data Center Max / Flex / Meteor Lake iGPU）。
  # 用 oneAPI Base Toolkit 的 icx/icpx 编译，GGML_SYCL=ON。
  # 强制 MKL：ggml/src/ggml-sycl/CMakeLists.txt 在 INTEL target 下
  # find_package(MKL REQUIRED)。默认 FP32（GGML_SYCL_F16=OFF，与 build.sh 和
  # main-intel.Dockerfile 默认一致）。
  build-linux-x86_64-sycl:
    runs-on: ubuntu-22.04
    steps:
      - name: Free up disk space          # oneAPI apt 安装约 3-5GB，先腾空间
        run: |                              # 完全复用 hip job 的清理脚本
          sudo apt-get remove -y '^dotnet-.*' '^llvm-.*' '^mysql-.*' '^postgresql-.*'
          sudo apt-get autoremove -y
          sudo rm -rf /usr/share/dotnet /usr/local/lib/android /opt/ghc /opt/hostedtoolcache/CodeQL
          df -h /

      - uses: actions/checkout@v7
        with:
          submodules: recursive
          ref: ${{ inputs.tag }}
          fetch-depth: 0

      - name: Install oneAPI Base Toolkit (DPC++ + MKL)
        run: |
          sudo apt-get update
          sudo apt-get install -y cmake g++ patchelf wget gnupg2
          # Intel oneAPI apt 仓库
          wget -qO - https://apt.repos.intel.com/intel-gpg-keys/GPG-PUB-KEY-INTEL-SW-9.PUB \
            | sudo gpg --dearmor -o /usr/share/keyrings/oneapi-archive-keyring.gpg
          echo "deb [signed-by=/usr/share/keyrings/oneapi-archive-keyring.gpg] https://apt.repos.intel.com/oneapi all main" \
            | sudo tee /etc/apt/sources.list.d/oneAPI.list
          sudo apt-get update
          # 仅装编译必需组件，避免整包 basekit（~10GB）撑爆磁盘
          sudo apt-get install -y \
            intel-oneapi-compiler-dpcpp-cpp \
            intel-oneapi-mkl-devel \
            intel-oneapi-tbb-devel
          # setvars.sh 写入 $GITHUB_ENV，供后续 step 继承 ONEAPI_ROOT 等
          source /opt/intel/oneapi/setvars.sh --force
          echo "ONEAPI_ROOT=$ONEAPI_ROOT" >> "$GITHUB_ENV"

      - name: Build
        run: |
          source /opt/intel/oneapi/setvars.sh
          cmake -S . -B build \
            -DCMAKE_BUILD_TYPE=Release \
            -DBUILD_SHARED_LIBS=OFF \
            -DGGML_SYCL=ON \
            -DGGML_BLAS=OFF \
            -DGGML_NATIVE=OFF -DGGML_AVX2=ON -DGGML_FMA=ON -DGGML_F16C=ON \
            -DCMAKE_C_COMPILER=icx \
            -DCMAKE_CXX_COMPILER=icpx \
            -DCRISPASR_BUILD_TESTS=OFF \
            -DCRISPASR_BUILD_EXAMPLES=ON \
            -DCRISPASR_BUILD_SERVER=OFF
          cmake --build build --target crispasr-cli crispasr-quantize -j $(nproc)

      - name: Package
        run: |
          set -euo pipefail
          source /opt/intel/oneapi/setvars.sh
          OUT=release/crispasr-linux-x86_64-sycl
          mkdir -p "$OUT/lib"
          cp build/bin/crispasr "$OUT/"
          cp build/bin/crispasr-quantize "$OUT/"
          # 列出实际 NEEDED 的 SYCL/MKL/TBB/Level-Zero 运行时并打包
          ldd "$OUT/crispasr" | awk '/=> \/opt\/intel/ {print $3}' | sort -u \
            | xargs -I{} cp -L {} "$OUT/lib/"
          # 也兜底常见 SONAME（防止 ldd 解析路径变化）
          for lib in libsycl.so.7 libm_sycl.so.7 libze_loader.so.1 \
                     libtbb.so.12 libsvml.so libirng.so libintlc.so.5; do
            found=$(find /opt/intel/oneapi -name "$lib" -type f 2>/dev/null | head -1)
            [ -n "$found" ] && cp -L "$found" "$OUT/lib/"
          done
          for f in "$OUT"/crispasr "$OUT"/crispasr-quantize; do
            patchelf --set-rpath '$ORIGIN/lib' "$f"
          done
          cd release && tar czf crispasr-linux-x86_64-sycl.tar.gz crispasr-linux-x86_64-sycl/
          ls -lh crispasr-linux-x86_64-sycl.tar.gz

      - uses: actions/upload-artifact@v4
        with:
          name: crispasr-linux-x86_64-sycl
          path: release/crispasr-linux-x86_64-sycl.tar.gz

      - name: Attach crispasr-linux-x86_64-sycl.tar.gz to release
        uses: softprops/action-gh-release@v2
        with:
          tag_name: ${{ inputs.tag }}
          files: release/crispasr-linux-x86_64-sycl.tar.gz
          fail_on_unmatched_files: false
```

### 2. 把新 job 加入 `publish.needs` 数组

在 `release.yml:1807` 的 `needs: [...]` 列表里，紧跟 `build-linux-x86_64-hip` 之后插入 `build-linux-x86_64-sycl`，保持 Linux GPU 变体聚集。

## 关键技术决策

| 决策 | 选择 | 依据 |
|---|---|---|
| 安装方式 | apt 在线安装 `intel-oneapi-compiler-dpcpp-cpp` + `intel-oneapi-mkl-devel` + `intel-oneapi-tbb-devel` | 用户选定；ggml-sycl/CMakeLists.txt 强制 `find_package(MKL REQUIRED)` |
| 编译器 | `icx` / `icpx`（来自 DPC++ 包） | README_sycl.md + build.sh + main-intel.Dockerfile 一致 |
| FP 模式 | FP32（`GGML_SYCL_F16=OFF`） | 与 build.sh 默认、Dockerfile 默认一致；FP16 为可选实验特性 |
| MKL | 强制 ON（由 CMakeLists 隐式启用，不显式传 flag） | ggml-sycl INTEL target 走 `find_package(MKL REQUIRED)` |
| BLAS | OFF | 与 Vulkan/CUDA/HIP 一致：GPU target 不需 OpenBLAS，省掉 libgfortran 依赖 |
| 磁盘 | 复用 hip job 的清理脚本 | oneAPI apt 约 3-5GB，runner 仅 14GB |
| 运行时打包 | `ldd` 抓取 `/opt/intel/*` 的 NEEDED + 手动兜底常用 SONAME | 用户选定；与 Vulkan job 一致，解压即用 |
| RPATH | `$ORIGIN/lib` via patchelf | 与所有 Linux job 一致 |
| setvars.sh | 在 Build/Package step 顶部各 source 一次 | `ENV{ONEAPI_ROOT}` 由 setvars 注入，ggml-sycl 据此识别 oneAPI 编译器 |

## 不做的事

- 不加 Windows SYCL job —— README_sycl.md「Todo: Support to build in Windows」表明上游未稳定
- 不改 `main-intel.Dockerfile` 或 `docker.yml` —— 现有 Intel Docker 镜像已是 SYCL，独立维护
- 不动 `publish` job 之外的发布逻辑
- 不改 `CMakeLists.txt` / `examples/sycl/` —— 现有 SYCL 编译路径已完备

## 风险与缓解

- **oneAPI apt key 轮换**：URL 用的是 Intel 官方长期 GPG key 路径，失效概率低；若失败，可见的错误信息明确指向 apt 源。
- **`libsycl.so.X` 主版本号变化**：手动兜底列表写的是当前版本（.7/.12/.5），即使 ldd 已抓全，列表只是冗余保险。
- **MKL 体积大**：若 tarball 过大（>100MB），可在后续迭代考虑改用 `-DMKL_INTERFACE=LP64` 等精简选项，但本计划保持默认配置以保证正确性。
